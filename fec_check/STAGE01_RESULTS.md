# F85-C 0–1단계 검증 결과 (2026-10-26)

대상 시스템:
- 부호: [256,239,6] extended BCH(t = 2)의 정사각 제품부호. N = 65,536, 부호율 0.8716.
- 복호기: 행 → 열 iBDD, 최대 10 sweep, 변화가 없으면 조기 종료.
- 채널: BSC(p).

비교한 두 복호기(같은 오류 행렬 사용):
- **실제:** 진짜 t = 2 BDD. 오수정이 일어날 수 있다.
- **기준:** 오수정 없는 genie. 성분의 참 오류 수가 2 이하일 때만 정정한다.

코드: `pcode.py`(BDD·iBDD), `floor_exp.py`(계열 추정·직접 MC), `instrumented.py` / `analyze_inst.py`(실패 프레임 기록·분류), `check_code.py`, `check_core_count.py`, `test_*.py`.

## 1. 구현 검증

- **A₆ = 5,757,696, α₄ = 15876/32131.** 무게 4 지지집합 중 오수정 가능한 것을 직접 세서 얻었고, 문서 값과 정확히 일치한다.
- **문서의 motif 재현:** 생성 motif(실제 9 / 기준 0), 구제 motif(실제 0 / 기준 9), 전치 motif(0 / 0)를 n = 256에서 재현했다.
- **문서 계수 정정:** 생성 계열의 4오류 행은 (W, core)당 **12가지**다(핵심 1 + 비핵심 3: 3가지, 핵심 2 + 비핵심 2: 9가지). 문서는 9가지로 셌다(M₁₀ = 540A₆C(n,3) → 720A₆C(n,3)).
- **3×3 core 조합식 검증:** E[#core] = C(n,3)²p⁹이다. p = 0.03, 0.035에서 측정 0.170, 0.695, 이론 0.150, 0.602로 통계 오차 안에서 일치했다.

## 2. 워터폴 위치

- **실제:** p ≈ 1.0–1.1×10⁻²
- **기준:** p ≈ 1.2–1.3×10⁻²

워터폴에서 오수정이 성능을 깎는 효과는 이미 알려진 현상이다(Häger–Pfister 2018).

## 4. 실패 경로 분류 (기록 프레임: p = 8.5×10⁻³ 9개, p = 7×10⁻³ 4개)

- 실제 복호기의 잔여 9 실패 **8개 전부**에서 초기 오류에 3×3 core가 **없었다**.
  - 최종 정체 패턴 9칸 중 초기 오류에 있던 칸은 5–8칸뿐이다. 나머지는 **오수정이 새로 써 넣은 오류**다.
  - 정체 패턴 행들의 초기 무게는 4–8이다. 4오류 행만 센 초기 패턴 계열(F1–F3)로는 이 대부분을 설명하지 못한다.
  - 그래서 초기 패턴 계열 추정은 실제보다 약 3–15배 낮게 나왔다(p = 7×10⁻³: 계열 2.1×10⁻¹⁰ 대 직접 5.2×10⁻¹⁰).
- 기준 복호기는 독립 seed 실험에서 실패가 0회였다. 같은 seed 실험의 기준 실패(1–2회)는 결합 표본에서 같은 프레임이 반복 집계된 것으로 본다.

## 5. Holzbaur–Bartz–Wachter-Zeh (arXiv:1704.01893v4) 대조

- 오류 바닥 추정식 (4)는 **(p + ξ)^ε** 형태다. ξ는 오수정(undetected error event)을 보정하는 경험적 계수이고, 저자들은 "ξ에 대한 해석적 bound는 어렵고 현재는 추정·시뮬레이션에 의존한다"고 명시한다.
  - 저자들은 staircase 255×255 부호(t = 2)에 대해 p = 5×10⁻³에서 ξ = 1.6×10⁻³으로 맞췄다. 이는 보정 배율 약 12배에 해당한다.
- 따라서 **"오수정이 오류 바닥을 높인다"는 현상 자체는 알려져 있다.** 위 R 값을 신규 발견으로 주장할 수 없다.
- **새로 확인한 것은 ξ가 상수가 아니라는 점이다.** 역산한 ξ/p는 0.32(7×10⁻³) → 0.6(7.5–8×10⁻³) → 0.74(8.5×10⁻³)로 p가 작아질수록 줄어든다. 7×10⁻³과 8.5×10⁻³(독립 seed)은 95% 구간이 겹치지 않는다.
  - 문서 9절에 따르면 p → 0에서 오류 바닥의 선도항은 오수정과 무관하므로, ξ/p → 0이 기대된다.
  - 반면 상수 ξ 모델은 p → 0에서 BER → (상수)·ξ⁹으로 가짜 바닥을 만든다. 논문 Fig. 9의 regular decoder 곡선이 낮은 p에서 평평해지는 것은 이 산물일 가능성이 있다(미검증).

## 6. 상수 ξ 외삽의 오차 (예비)

측정 가능 영역(p = 8.5×10⁻³)에서 ξ = 6.3×10⁻³로 맞추고 상수로 외삽해 보았다.
- **p = 7×10⁻³:** 상수 ξ 모델은 BER 1.4×10⁻⁸을 예측하지만, 실측은 5.2×10⁻¹⁰이다. **약 26배 과대예측**이다(구간 약 10–90배).
- **목표 BER 10⁻⁹ 운용점:** 상수 ξ 모델은 p ≈ 3.7×10⁻³을 예측하고, 실측 곡선은 p ≈ 7.1×10⁻³에서 도달한다(7–7.5×10⁻³ 사이 로그 보간). 경판정 SNR로 환산하면 약 **0.8 dB** 차이다.
- 한계:
  - 실측은 7×10⁻³까지뿐이다. 7×10⁻³ 아래의 실제 곡선은 아직 모른다(계열 추정은 하한에 해당).
  - 실무에서 ξ를 어느 p에서 맞추느냐에 따라 이 차이는 달라진다.
  - 이 결과는 단일 부호(제품부호)에서만 나왔고, staircase에서는 확인하지 않았다.

## 7. 판정

- **0a단계(문헌):** 현상은 기존 연구에 있다(ξ). 다만 ξ의 해석적 규명은 저자들이 명시한 열린 문제다. → 목표를 "ξ(p)의 해석적 규명과 상·하한"으로 재정의한다.
- **0b단계(초기 패턴 조건 표본추출로 충분한가):** 불충분하다. 오류 바닥 실패의 대부분이 초기 core를 포함하지 않는 동적 생성 경로다.
- **1단계:** ξ = 0 대비 차이는 크지만(12–165배) 신규성은 아니다. 신규성 후보는 **ξ의 p 의존성**과 **상수 ξ 외삽의 오차**(예비로 약 26배, 10⁻⁹ 운용점 약 0.8 dB)다.
